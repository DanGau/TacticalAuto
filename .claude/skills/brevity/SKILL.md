# Brevity

A passage is **brief** when deleting any word loses information.
A passage is **precise** when a reader with the stated context recovers exactly one meaning.

## Cut

1. **Words that mean nothing.** actually, really, basically, essentially, certainly, very, quite, simply, just.
2. **Words that repeat other words.** each and every → each; first and foremost → first; various different → various; true facts → facts.
3. **Words implied by other words.** final outcome → outcome; past history → history; future plans → plans; completely finish → finish; end result → result.
4. **A phrase where a word will do.** due to the fact that → because; in the event that → if; has the ability to → can; there is a need for X → X must.
5. **Negatives that hide an affirmative.** not different → the same; does not have → lacks; not many → few.
6. **Talk about the text.** as you can see; it should be noted; as this section describes; we will now; I believe.
7. **Passive where the actor matters.** "is called by the worker" → "the worker calls".
8. **Long, jargon, or borrowed words.** Use the everyday word: utilize → use; prior to → before; via → through.

## Keep

1. **The step that seems obvious.** You know it; the reader does not.
2. **The definition of a coined term.** Define it at first use.
3. **The hedge that is true.** "Usually" stays if the claim has exceptions.
4. **The word that kills a second reading.** If a sentence has two readings, add it.

Break any rule above before you write something unclear.

## In code

- Comments say what code can't: intent, constraints, non-obvious trade-offs. Never what the code says.
- Names carry no filler: `users`, not `theListOfAllUsers`.
